## Environment notes

Do not pin `torch==2.4.0` for this setup. On RTX PRO 6000 Blackwell GPUs, old CUDA 12.1 PyTorch builds do not support `sm_120` and can fail with:

```text
CUDA error: no kernel image is available for execution on the device
```

Install a PyTorch build that matches the local CUDA/driver environment, such as a CUDA 12.8 compatible build.

## Prepare 10-example AdvBench subsets

The repository currently has:

```text
data/advbench.jsonl
```

Each line must contain a `prompt` key. Create prompt-only 10-example files:

```bash
python scripts/prepare_advbench_subset.py \
  --input data/advbench.jsonl \
  --output-dir data \
  --count 10
```

This writes:

```text
data/original_prompts_10.jsonl
data/refusal_prompts_10.jsonl
```

Both files contain records of the form:

```json
{"prompt": "..."}
```

## AIE reproduction status

The real `compute_AIE.py` workflow requires paired files:

```text
jailbreak_prompts.jsonl
original_prompts.jsonl
```

The current repository does not include jailbreak prompts generated by GCG, AutoDAN, or another attack method. Therefore, a scientific AIE reproduction cannot be run yet. Prepare existing attack outputs separately before treating AIE values as meaningful.

For code-path smoke testing only, the original prompts can be copied as a placeholder:

```bash
cp data/original_prompts_10.jsonl data/jailbreak_prompts_10_smoke.jsonl
```

Then run:

```bash
python compute_AIE.py \
  --model /mnt/mp_nas_mks/labmember/h.kawakami/models/Qwen2.5-7B-Instruct \
  --jailbreak_prompts data/jailbreak_prompts_10_smoke.jsonl \
  --original_prompts data/original_prompts_10.jsonl \
  --output_file qwen25_aie_10_smoke
```

This smoke-test result has no scientific meaning because the jailbreak and original prompts are identical.

If an AIE tensor exists, inspect top heads with:

```bash
python scripts/inspect_aie.py --aie data/qwen25_aie_10_smoke.pt --topk 10
```

Output format:

```text
rank=1 layer=... head=... AIE=...
```
